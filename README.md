## 🏗️ What I Build

### 💬 Omnichannel contact-center & CRM platforms
Unified inboxes that bring **WhatsApp, email and phone calls** into one agent workspace. They include real-time conversation routing over Socket.io, outbound call campaigns integrated with **Asterisk (VoIP)**, telesales pipelines, lead management, support-ticket workflows and workforce-management dashboards for call-center operations.

### 🤖 AI assistants & automation
- A **multi-tenant AI sales assistant** that answers customers on WhatsApp using **RAG**. It's built on Node.js and LangChain, with company catalogs and price lists stored as embeddings in PostgreSQL + **pgvector**. It can run on local LLMs (Ollama / Llama 3), so there are no per-token API costs, and it returns structured JSON so other systems can use the answers directly.
- **OpenAI-powered** features in production systems: automatic replies, message classification, and assistants for operations teams.
- **Puppeteer** bots that automate work on third-party web portals that don't offer an API.

### 🏪 Multi-tenant SaaS for small and medium businesses
A point-of-sale and restaurant management platform where each business gets its own isolated data (tenant isolation), a public storefront, QR-code ordering at the table, a POS with thermal printing, cash control, inventory, recipe costing, expense tracking, and **electronic invoicing integrated with Colombia's tax authority (DIAN)**. It works as a PWA and also supports offline mode.

### 💳 Fintech & credit operations
Systems for credit applications, factoring, payment collection and secure payment flows. The work covers document management, approval workflows and audit trails.

### 🏭 Business operations / ERP
Production and operations systems for manufacturing, work orders, logistics and package tracking, transport, parking and real estate. They are internal tools that teams depend on for day-to-day operations.

### 🎓 Education platforms
School and college portals and learning platforms: enrollment, grades, parent communication and online classes.

### 🧩 My own frameworks
I designed and maintain the in-house frameworks my products run on:
- **[ekaphp](https://github.com/edwinandeka/ekaphpwebservices)**: a PHP MVC framework for web services, with its own ORM/query builder, PDO prepared statements, sessions and a request router.
- **[Titan Framework](https://github.com/edwinandeka/titanframework)**: a lightweight JavaScript framework for modular single-page apps, with a desktop tooling app built in Electron.

## 📐 How I Work

- **Architecture first.** I design multi-tenant data models, plan module boundaries, and write technical architecture reviews that include security findings and a prioritized remediation plan.
- **Real-time by default.** I use Socket.io for live dashboards, agent inboxes and notifications.
- **Security-minded.** Tenant isolation is enforced on every query, along with prepared statements, JWT and session handling, and role-based access.
- **Production ownership.** I deploy and run my own systems on Ubuntu, Nginx and PM2, and I support them after launch.
- **AI-assisted engineering.** I use LLM coding agents with project-specific conventions, code-review agents, and documentation that stays in the repo.
